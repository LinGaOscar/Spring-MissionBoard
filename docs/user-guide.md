# 使用說明

本文件說明 Spring-MissionBoard 的角色權限與各項可用功能，適合系統使用者（非開發者）閱讀。開發環境建置請見 [dev.md](dev.md)。

## 登入

- 開啟系統後導向 `/login`，以帳號密碼表單登入。
- 登入成功導向首頁（`/home`），目前首頁僅顯示歡迎訊息，實際操作請由「專案列表」進入。
- 未登入時，一般頁面會被導回登入頁；API 請求則回傳 401。

## 角色與權限

系統有四種角色，權限範圍由高至低如下：

| 角色 | 顯示名稱 | 可讀範圍 | 可寫範圍 | 可封存／還原專案 |
|---|---|---|---|---|
| `DIRECTOR` | 主任 | 全部科別的所有專案（跨科） | 一律唯讀，不可寫入任何專案 | 不可 |
| `SECTION_CHIEF` | 科長 | 僅同科別的所有專案 | 同科別且**未封存**的專案 | 可（同科別，不受封存狀態限制） |
| `PROJECT_LEADER` | 專案負責人 | 僅自己參與（成員）的專案 | 自己參與且**未封存**的專案 | 可（僅限自己參與的專案） |
| `PROJECT_MEMBER` | 專案成員 | 僅自己參與（成員）的專案 | 自己參與且**未封存**的專案 | 可（僅限自己參與的專案） |

補充說明：

- **封存專案＝全員唯讀**：專案一旦封存，即使是科長或負責人也無法修改任務、分類或成員，只能檢視；「封存」動作本身刻意不受此限制，否則封存後會沒有人能還原。主任始終唯讀，不能封存或還原任何專案。
- **科別隔離**：專案列表依角色不同而不同——主任看到全部；科長看到本科全部專案；專案負責人／成員只看到自己被加入的專案，不受科別限制（即使被拉進其他科的專案也看得到）。
- 目前 `PROJECT_LEADER` 與 `PROJECT_MEMBER` 在系統權限判斷上完全相同，沒有額外差異化的操作。

### 測試／示範帳號

以下帳號僅供本機測試環境使用，密碼皆為 `password123`：

| 帳號 | 角色 | 所屬科別 | 參與專案 |
|---|---|---|---|
| `director` | 主任 | 資訊部（部級） | 無直接參與，可跨科唯讀所有專案 |
| `chief` | 科長 | 系統科 | 無直接參與，可讀寫系統科所有專案 |
| `leader` | 專案負責人 | 系統科 | 「MissionBoard 範例專案」負責人兼成員 |
| `member` | 專案成員 | 系統科 | 「MissionBoard 範例專案」成員 |
| `member2` | 專案成員二 | 網路科 | 未加入任何專案，用於驗證跨科看不到系統科專案 |

## 主要功能

### 專案列表

- 進入「專案列表」頁會列出目前使用者可讀的（未封存）專案卡片，每張卡片顯示專案名稱、所屬科別與負責人。
- 點卡片進入該專案的詳情頁。

### 專案詳情頁

進入專案後有三個分頁，畫面上方切換：

#### 1. 看板（預設分頁）

- 任務依狀態分「未開始／進行中／已完成」三欄呈現，可拖曳卡片跨欄改變狀態，或在欄內拖曳調整順序。
- 有寫入權限時可點「新增任務」開啟編輯視窗建立任務，新任務預設「未歸類」。
- 點任一卡片可開啟編輯視窗，修改標題、描述、指派人、所屬分類、優先度、起訖日，或刪除任務。
- 逾期任務（到期日已過且尚未完成）以紅色標示；已完成的任務不會被標示逾期。
- **分類管理面板**（工具列可展開）：
  - 從預設選單挑選「階段（大類）」或「子類別」加入專案的分類樹（無法自由輸入名稱，需從選單挑選）。
  - 雙擊分類名稱可就地改名。
  - 拖曳分類列可調整同層排序（僅限同一層內，無法跨層拖曳）。
  - 刪除分類：若該分類有子類別會一併刪除，其下任務會自動變回「未歸類」，不會被刪除。

#### 2. 人員派工

- 以專案成員為欄（含「未指派」欄）呈現任務卡片，可拖曳卡片跨欄改變指派人。
- 可用「顯示已完成」開關切換是否顯示已完成任務（預設隱藏）。
- 欄內任務依到期日排序，無到期日的排最後。
- 此分頁僅支援拖曳改指派，不支援點卡片開編輯視窗；完整編輯請回看板分頁操作。

#### 3. WBS 檢視

- 以「大類 → 子類別 → 任務」樹狀結構呈現，並固定顯示「未歸類」節點。
- 每個節點旁顯示任務數與完成度。
- 可拖曳任務到不同的分類節點，改變該任務所屬的大類／子類。
- 點任務列會開啟與看板相同的編輯視窗。
- 分類本身的新增／改名／刪除／排序，仍只能在看板分頁的「分類管理」面板操作，WBS 檢視不提供。

### 任務欄位

任務可編輯的欄位：標題（必填）、描述、指派人（限專案成員）、所屬分類（未歸類或任一分類）、優先度（高／中／低／未設定）、起始日、到期日、狀態。

## 目前尚未提供操作介面的功能

以下功能後端 API 已存在，但前端尚未提供對應按鈕／表單，僅供未來版本規劃參考：

- 建立新專案、封存／解封存專案、更換專案負責人
- 專案成員的新增／移除管理畫面
- 任務資料匯出（Excel）
